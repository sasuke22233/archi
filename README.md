# ARCHISTUDY — интерактивный учебный сайт

React + Vite учебный сайт по предоставленному материалу курса «Проектирование».

## Что внутри
- адаптивная верстка для ПК и телефона;
- главная страница с минималистичной визуальной системой;
- «Материал» — 52 главы и полный постраничный текст 912-страничного PDF;
- поиск по полному тексту материала;
- «3D-лаборатория» — интерактивные CSS 3D-сцены: колонна, каркас, арка, стена + ядро жесткости;
- переключение слоев «каркасная сетка» и «нагрузка»;
- «Вопросы» — 30 вопросов «ЗАУЧИТЬ» и 25 «ПОДУМАТЬ»;
- для каждого ответа есть отдельный блок «Цитата из материала» с номером страницы;
- исходные PDF лежат в `sources/`.

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Для production:

```bash
npm run build
npm run preview
```

## Структура
- `src/main.jsx` — интерфейс и страницы;
- `src/styles.css` — адаптивный дизайн;
- `src/chapters.js` — 52 главы;
- `src/answers.js` — 55 вопросов и ответы с цитатами;
- `src/materialPages.js` — полный текст PDF постранично;
- `sources/` — исходные материалы.

Содержание сайта основано на предоставленных пользователем PDF и не заменяет проверку исходного документа.
